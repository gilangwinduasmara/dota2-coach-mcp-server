[ 03 / Deploy ]

Two commands. No keys.

Works in Claude Code, Claude Desktop, and claude.ai. No local setup, no accounts.

01

Add the marketplace

>>> /plugin marketplace add gilangwinduasmara/dota2-coach
02

Install the plugin

>>> /plugin install dota2-coach@dota2-coach

Registers the coaching skill and the analyze_dota2_match tool automatically.

03

Ask Claude to review a match

> Can you review this game for me? https://www.dotabuff.com/matches/7891234567
04

Optional: force full coaching depth

>>> /dota2-coach:analyze-match Can you review this game for me? https://www.dotabuff.com/matches/7891234567

Plain-language requests usually just call the analyze_dota2_match tool directly. Invoking the skill explicitly (Claude Code) guarantees the full report structure and rating tables get used.
