Give Claude a Dota 2 match ID. Get back a real coaching report: laning, farming, deaths, itemization, objectives, teamfights, and benchmark percentiles vs. your rank bracket.

What you get

  • Laning phase breakdown
  • Farm pattern & timelines
  • Death log analysis
  • Itemization & skill build
  • Rune control
  • Objectives & teamfights
  • Benchmark percentiles
  • Full-match rating tables

Install

  1. Add the marketplace

    In Claude Code, Claude Desktop, or claude.ai:

    /plugin marketplace add gilangwinduasmara/dota2-coach

  2. Install the plugin

    /plugin install dota2-coach@dota2-coach

    This registers the coaching skill and the analyze_dota2_match tool automatically, no local setup, no API keys.

  3. Ask Claude to review a match

    “Can you review this game for me? https://www.dotabuff.com/matches/7891234567”
